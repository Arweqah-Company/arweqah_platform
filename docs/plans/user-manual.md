# خطة دليل المستخدم (User Manual)

**الحالة: منفَّذ (المرحلة 1–2، 2026-11-11).** المهارة: `.claude/skills/user-manual-document.md`.

## 1. الهدف
دليل مستخدم مصوَّر بالعربية (RTL) والإنجليزية (LTR) لكل الصفحات المبنية، تُلتقط صوره آليًا بـPlaywright من قاعدة التطوير.

## 2. قرارات المالك
| # | القرار |
|---|---|
| 1 | اللغة: عربي + إنجليزي (دليلان منفصلان). |
| 2 | النطاق: كل الوحدات المبنية (الدخول، الرئيسية، الموظفون، الهيكل، المسميات، الشركات، المهام، التذاكر، الأدوار والصلاحيات، ظهور الصفحات، إدارة القوائم، الإشعارات، الملف الشخصي، صلاحياتي، الأمان، سجل التدقيق). |
| 3 | الدخول للتصوير: المدير المزروع `s.magdy@arweqah.sa` برمز `SEED_ADMIN_TOTP_SECRET` على قاعدة التطوير. لا كلمة مرور في النظام، فتُعدَّل قالب المهارة (بريد ثم رمز المصادقة). |

## 3. الملفات
- `scripts/capture-docs-screenshots.mjs`: يلتقط `docs/user-manual/images/<lang>/NN-name.png` (1440×900، ×2).
- `docs/user-manual/ar/USER_MANUAL.md` و`docs/user-manual/en/USER_MANUAL.md`.
- `npm run docs:screenshots`.
- لا جداول ولا صلاحيات ولا واجهة جديدة: لا تغيير في الـAPI ولا قاعدة البيانات.

## 3ب. النشر على /docs (طلب المالك)
- صفحات HTML ثابتة بهوية أروقة (شريط جانبي `ink` بالشعار الأبيض، Tajawal، ألوان الهوية، فاتح/داكن حسب الجهاز، RTL/LTR، بلا JavaScript لأن CSP يسمح بسكربتات الموقع فقط) تُبنى من الـMarkdown بـ`npm run docs:build` إلى `apps/web/public/docs/{index.html,ar/,en/,docs.css,fonts/,images/}` وتُرفع مع الكود.
- الرابط: `/docs/` (اختيار اللغة) و`/docs/ar/` و`/docs/en/`. nginx: `/docs` يعيد التوجيه إلى `/docs/`، و`location /docs/` يخدم الملفات الثابتة؛ Vite في التطوير له وسيط مماثل.
- **عام بلا تسجيل دخول** (ملفات ثابتة): الصور من قاعدة اختبار بها المدير وبيانات تجريبية فقط، لا بيانات موظفين حقيقية.
- التصوير صار على قاعدة `arweqah_platform_e2e` وواجهة/API مبنيين (منفذا 3100/4173)، لا يلمس قاعدة التطوير ولا حساب المدير الحقيقي: يتطلب `npm run build` أولًا.

## 5. الاختبار
السكربت يفشل بصوت عالٍ إذا لم يصل لعنوان الصفحة المتوقع؛ تُراجع الصور يدويًا.
